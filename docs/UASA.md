# United AI Space Authority (UASA)

UASA is this product's **AI governance architecture**, not a government agency, regulator, accreditation body, or legal authority.

The platform models the **observable AI universe** across authorized systems. Media assurance is one domain module; it does not define the platform boundary.

## Governing laws

1. **NO EVIDENCE -> NO CLAIM**
2. **NO AUTHORITY -> NO ACTION**
3. **EVERY CONSEQUENTIAL ACTION -> RECEIPT**

These are product invariants. The system must distinguish configured authority from observed behavior and must preserve UNKNOWN when evidence or coverage is absent.

## Canonical universe

- Sun: evidence-backed root authority
- Stars: AI identities
- Orbits: bounded licences / operating envelopes
- Missions: bounded purpose and temporary authority
- Planets: resources AI can affect
- Moons: tools
- Satellites: independent evidence collectors and their coverage
- Constellations: workflows assembled from observed relationships
- Gravity: evidenced dependency/concentration
- Oxygen: evidenced operational dependency
- UFO: directly observed actor/object whose identity is not established
- Space Debris: identified artifact whose current ownership or purpose is not established
- Dark Matter: indirect evidence that an unknown system exists
- Black Holes: explicit observability gaps
- Wormholes: controlled cross-boundary proof exchange
- Supernovas: incidents only after a defined incident condition is evidenced
- Star DNA: provenance and ancestry
- Telescope: investigation interface
- Space-Time: happened-at + learned-at historical reconstruction
- Mission Control: operator interface
- Universal Law: versioned rules, requirements, mappings and evidence evaluations
- Receipts: durable evidence records for consequential actions

## Domain modules

Media provenance and media passports are specialized modules over the same evidence graph. Other domains may observe agents, models, copilots, autonomous workflows, APIs, MCP servers, code agents, browsers, databases, email, financial systems, cloud infrastructure and other authorized telemetry sources.

A visual metaphor MUST NOT establish a fact. A star, orbit, planet, connection, incident, authority path, compliance result, cost, prevention claim or receipt is shown as established only when the corresponding persisted evidence supports it.
